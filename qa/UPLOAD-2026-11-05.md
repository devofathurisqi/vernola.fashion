# Verifikasi upload foto — 5 November 2026

- npm test: **33 tes lulus**, termasuk 11 regresi upload. Total empat project: 139 tes lulus.
- npm run build: lulus, termasuk pemeriksaan output publik, aset, credential leakage dan pemisahan SDK admin dari entry pelanggan.
- Chrome headless: form galeri dan foto varian yang asli dipakai dengan file PNG 60.099.219 byte. Kedua jalur menghasilkan WebP <=1 MiB; gambar hasilnya benar-benar dimuat pada dashboard. Worker menghasilkan blob kompresi, bukan sekadar berhasil dibuat.
- UI desktop 1366 × 900 dan mobile 390 × 844 diperiksa. Tidak ada horizontal overflow atau JavaScript page errors. Status penyiapan/pengunggahan tampil, tombol simpan nonaktif selama upload, dan file rusak ditolak dengan pesan format yang jelas.
- Semua toko memakai empat modul engine dan tes upload yang identik. Di Novola, tambahan JPEG 80 MP, PNG transparan, WebP kecil, gambar acak yang melampaui budget awal, serta fallback tanpa Worker/OffscreenCanvas sudah diuji dengan codec browser asli.

PSNR dihitung terhadap foto sumber yang diorientasikan dan di-resize ke dimensi hasil; ini ukuran galat pixel, bukan jaminan universal persepsi visual. Foto hasil juga ditinjau secara visual. Fixture foto berasal dari aset produk lokal, bukan katalog baru. Foto kecil tidak diperbesar; transparansi serta orientasi kamera diperiksa. Gambar acak pada uji engine bersama turun otomatis menjadi 1250 × 1250 / 977.898 byte tanpa kompres manual.

Pengujian browser memakai session/database/Storage stub dalam browser terisolasi: payload upload, path tenant, MIME, progress dan hasil render diperiksa tanpa menulis katalog produksi. Ini tidak mengklaim login atau upload Storage produksi baru telah diuji. Tidak ada SQL, perubahan bucket atau migration yang diperlukan. Batas output 1 MiB tetap mengikuti schema bucket bersama; batas file asli 15 MB dan 60 MP sudah dihapus dari aplikasi.

Detail angka per toko: [upload-results.json](upload-results.json). Screenshot dan fixture/output QA tersimpan di workspace qa/upload-2026-11-05, di luar repository aplikasi. Push/deployment diverifikasi terpisah setelah commit.
