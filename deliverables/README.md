# Materi promosi paket katalog dan dashboard

Video vertikal 1080 x 1920, 30 fps, 34 detik. MP4 H.264 + AAC dengan faststart, narasi bahasa Indonesia, subtitle tertanam, dan musik hasil sintesis asli. Ukuran video sekitar 2,5 MB. Format siap dibagikan atau diunggah ke kanal promosi.

Untuk unduhan dari HP, gunakan https://vernola-fashion.vercel.app/unduh-video/ . Tombol MP4 dan ZIP memakai file satu origin dengan header Content-Disposition attachment. MP4 asli dan ZIP yang berisi file identik disimpan di public/downloads agar ikut deploy. File ini hanya diambil ketika halaman unduh/video diakses, bukan pada halaman katalog pelanggan.

Tampilan diambil dari build Novola.fashion yang sebenarnya setelah koreksi nama dan penghapusan 27 listing Vuyama dari tenant. Draft pesan WhatsApp pada adegan promosi diberi label contoh. Tidak ada pesan yang dikirim dalam pembuatan materi.

- Promo-Katalog-Dashboard-350-Novola.mp4: video final dengan narasi, subtitle dan musik.
- Cover-Promo-Katalog-Dashboard-350.jpg: cover video.
- Subtitle-Promo-Novola.srt: subtitle yang dapat diedit.
- CAPTION.txt: contoh teks unggahan.
- Panduan klien PDF dan sumber teks ada di ../docs/.

Penawaran mengikuti instruksi pemilik: Rp350.000 sekali bayar untuk katalog + dashboard. Materi tidak menjanjikan hasil penjualan atau hosting tanpa batas. CTA menggunakan “Chat saya” agar tidak mengarahkan calon pembeli jasa ke nomor pelanggan Novola.
